一、完整世界观（扩充细化版）
1. 核心法则：残影定律
•	定义：人在极端情绪状态下意外死亡，生前最强烈的执念会附着在死亡发生的空间与高频接触的物品上，形成“残影”。残影并非鬼魂，而是执念凝结的能量印记，无完整自我人格，只会遵循生前最核心的行为逻辑循环往复。
•	基础特性：
•	常态下残影不可视、不可触，仅能造成轻微环境扰动，机械重复生前最后的行为模式，无自主意识。
•	每日零点至凌晨两点为「窗口期」，残影会获得短暂具象化能力，可干涉物理环境；执念极强的残影会保留碎片化的自主意识，能与活人产生交互。
•	残影无法离开执念绑定的核心区域，一旦脱离绑定载体就会快速消散；执念越强，绑定的范围越大、存续时间越久。
•	残影分型：
•	无害型：多为猝死、意外身亡的普通人，执念多为未完成的工作，仅重复生前行为，无攻击性，是大厦内数量最多的残影。
•	怨恨型：因仇恨、报复心理死亡，残影带有强烈恶意，会主动攻击、困锁活人，试图将其拉入自身的死亡循环，转化为新的残影。
•	守护型：因保护他人、履行职责的执念死亡，残影保留完整理性与善意，会主动帮助活人，对抗怨恨型残影；同一区域内，守护型与怨恨型残影会长期互相牵制。
2. 数字残影专属设定
•	成因：若死者生前长期高频接触电子设备与内部网络，执念会顺着电路与数据浸染至系统中，形成“数字残影”，是残影的特殊存在形式。
•	载体限制：数字残影只能存活于大厦封闭内网系统中，无法连接外网；可在同一内网的不同设备、不同楼层节点间移动，但不能突破物理服务器的边界。
•	侵染四阶段：
1.	一阶·微扰：仅能触发设备自启、文件移位、打印任务异常等轻微故障，常人只会以为是设备老化。
2.	二阶·篡改：可篡改页面内容、发送匿名邮件、调用低权限系统模块，零点后常态生效。
3.	三阶·干涉：可弹出幻象画面、制造感官干扰、控制用户设备操作，对活人形成精神压迫，怨恨型残影可主动触发。
4.	四阶·锚定：将活人的意识锚定在系统内，使其成为新的数字残影，永远困在内网中重复死亡前的行为。
•	存续逻辑：数字残影依附于旧系统数据碎片存在，只要对应的历史数据未被彻底物理删除，残影就不会消失。常规的系统重装、格式清理无法根除执念附着的数据碎片。
•	消解条件：怨恨型残影需摧毁其核心执念载体（数据形态的执念物品）；守护型残影完成未竟的执念后，会自愿消散。
3. 星辉大厦背景时间线
•	1999年：星辉大厦建成投入使用，同步上线第一代物业内网系统v1.0，是当时本市智能化程度最高的写字楼。
•	2003年：大厦入驻率达顶峰，8楼为鼎盛贸易公司办公区，周建任该公司行政专员；陈国华入职大厦保安队，负责夜间巡逻。
•	2004年7月12日：深夜发生特大火灾。官方通报起火点为配电室，系电路老化所致，夜班保安陈国华遇难。实际起火点为8楼鼎盛贸易公司办公室，系被辞退的员工周建纵火报复，周建本人也葬身火海。陈国华本已逃生，折返上楼救人时遇难。
•	2005年：大厦翻新完成，内网系统升级为v2.0，旧系统的全部历史数据被打包备份至服务器深处，未做彻底清除。同年首次出现“深夜加班遇怪事”的员工反馈，未被重视。
•	2010-2020年：每隔1-2年就有深夜加班的员工提交离职申请，理由多为“精神压力大”“办公环境诡异”。物业内部默认“零点后清空大楼”的潜规则，但从未对外解释原因。
•	2024年至今：大厦多次更新办公系统，但旧备份数据一直遗留在服务器底层。零点窗口期，旧系统会短暂覆盖新系统界面，数字残影随之苏醒。“午夜加班会被系统困住”的传说在入驻公司间悄悄流传。
4. 内网势力格局
•	陈国华（守护型数字残影）：依附于保安值班系统与消防联动系统，是大厦内最强的残影。二十年来一直在零点窗口期巡逻，阻拦周建的残影伤害深夜加班的员工，会通过匿名邮件、系统提示给活人发出警告与指引，核心执念是“守好大楼，保护里面的人”。
•	周建（怨恨型数字残影）：依附于8楼旧公司站点与服务器底层数据，核心执念是报复公司、报复所有“还能正常上班的人”。零点时会试图突破防火墙，入侵仍在使用的办公系统，将登录内网的活人困在系统中，化为新的残影。
•	零散上班族残影：分布在各楼层的旧文档、旧邮箱中，多为当年火灾遇难的加班员工，仅重复工作行为，无攻击性，其留存的文档与记录是解开真相、完善世界观的关键线索。
