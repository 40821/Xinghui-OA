# 星辉大厦零点登录

都市微恐主题网页解谜游戏

## 游戏简介

你是广告公司策划专员林默，深夜独自在星辉大厦加班。零点钟声敲响的瞬间，办公系统被二十年前的旧版本覆盖，你被困在了大厦内网之中。

探索邮件、文档、监控和档案库，揭开2004年那场火灾的真相，在数字残影将你吞噬之前找到出路。

## 操作方式

- 点击左侧导航栏切换系统模块
- 点击文档/邮件查看详情
- 在密码弹窗中输入4位数字密码解谜
- 入侵倒计时出现时，点击顶部红色警告栏的「立即阻断」按钮

## 游玩时长

约30-40分钟

## 结局

- 好结局：成功清除残影，逃出大厦
- 普通结局：强制断开内网逃离，但残影仍在
- 坏结局：被残影成功入侵，成为新的数字残影

## 线索提示

所有密码均可在游戏内的文档、公告、邮件中找到对应线索，仔细阅读每一份文件。

## 运行方式

双击 index.html 即可在浏览器中运行，无需安装任何依赖。
